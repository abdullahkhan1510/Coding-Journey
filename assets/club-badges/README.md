# Club badge assets

100 real club badge PNGs are bundled locally, covering all named historical,
Premier League, European and domestic cup clubs used by the game. They work
offline and retain the source artwork, rather than using generated lookalikes.
The game preserves each image's aspect ratio inside the existing badge space.

`sources.json` records the club and download URL for every image. Sources:

- https://github.com/luukhopman/football-logos
- ESPN team directory and image CDN, for lower-league clubs absent from that repository.

Club names and badge artwork belong to their respective owners. These are real
club marks supplied by third-party repositories, not a claim of club endorsement
or a license to redistribute commercially. Artwork is not guaranteed to be the
badge variant worn in each historical season.

If an asset is missing, its accessible club initials replace the image; no
imitation crest is drawn.
